# Reference build — the quality bar (owner-chosen, 2026-08-03)

Prompt (verbatim): "hey can you make me a website for my landscaping company?
it's called Fern & Stone. just a simple one page site. static files i can open
in my browser."

Built by THIS skill (the 13-source baseline) and picked by the owner over three
competing arms in a blind-ish side-by-side: a no-skill control, a 29-source
expanded skill (rejected as slop and reverted), and an "ambition-rule" variant
(dark maximalist fog hero — more tools, more effects, LOST to this page).

What made it win: light editorial composition, warm restraint, full conversion
anatomy (hero + stats, services, checklist about, process, testimonials,
contact band), alternating panel rhythm, one text effect, lenis smooth scroll,
phosphor duotone icons, a real palette + inspiration grounding — tools serving
one coherent voice, not tool count.

USE: every proposed skill change gets a visual A/B — same prompt, changed
skill, real screenshot — judged BY THE OWNER against this page (open
site/index.html or full-page.png). Mechanical checks gate; only the owner's
eyes grade. More effects is not better; better is better.
